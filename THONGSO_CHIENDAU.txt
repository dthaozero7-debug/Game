# Combat Flow

1. So speed
2. Nguoi nhanh dung skill
3. Neu doi thu chet -> skip damage
4. Nguoi cham dung skill
5. Neu doi thu chet -> skip damage
6. Ap dung he khac che
7. Roll crit
8. Exchange damage
9. Check death

# Damage Logic

- ATK tru DEF
- DEF tru ATK

# Death Rule

- Neu chi so <= 0 -> chet
- Neu ca 2 cung chet:
  - Neu la tuong cuoi:
    - Ben phong thu thang
  - Nguoc lai:
    - Hoa
